# إدارة حلقات تحفيظ القرآن

تطبيق ويب عربي (RTL) لإدارة حلقات التحفيظ: الأماكن والحلقات، والطلاب، والمعلمون والمشرفون، والحضور والتسميع، والاشتراكات والتحصيل، والمرتبات وغياب المعلمين.
مكتوب بـ HTML وCSS وJavaScript فقط، بلا خطوة بناء، ويعمل كتطبيق PWA على الجوال والحاسوب، ومنشور على Vercel، وبياناته على **Supabase**.

## البيانات والمزامنة

- البيانات **مشتركة بين كل الأجهزة** عبر Supabase، والصلاحيات الحقيقية مطبّقة على الخادم بقواعد RLS على كل الجداول (الواجهة لا تُعتمد للحماية).
- يعمل التطبيق على نسخة محلية في قاعدة بيانات المتصفح (IndexedDB)، فيفتح ويعمل **بدون إنترنت**، وتُرسل التعديلات تلقائيًا عند عودة الاتصال (الفروق فقط).
- المزامنة بالتغييرات فقط: كل مستخدم ينزّل نطاقه (المعلم حلقاته، والمشرف حلقاته…)، وتُحفظ آخر مزامنة على الجهاز فيُجلب عند الفتح ما تغيّر منذها فقط.
- عامل الخدمة `sw.js`: الشبكة أولًا ثم النسخة المحفوظة؛ والتطبيق يكتشف الإصدار الجديد بنفسه.

## الدخول وأنواع الحسابات

دخول موحّد: يكتب المستخدم بعض حروف اسمه ويختاره ثم كلمة المرور. أنواع الحسابات المعتمدة:

| النوع | ما يراه ويفعله |
|---|---|
| **مدير** | كل شيء. حساب النظام لا يظهر ضمن «الموظفون» |
| **مشرف** | حلقاته المسندة: الحضور والتسميع وغياب المعلمين. و**المشرف العام** (من زر «النطاق») يرى كل الحلقات |
| **معلم** | حضور حلقاته وتسميعها، وتحصيل اشتراكات طلابه وإرسالها للمحاسب، وملفه |
| **محاسب** | الاشتراكات ومراجعة قوائم التحصيل، بحسب «الصلاحيات» |
| **إداري** (في مكان) | يطّلع على حلقات أماكنه وطلابها، ويجمع اشتراكاتهم ويرسلها للمحاسب |
| **طالب** | حفظه وحضوره وسجله والإعلانات (ومنها تأكيد الدفع والتذكير بالسداد) |

كلمات المرور تُنشأ بعشر خانات (بادئة بحسب النوع + 6 أرقام) وتُسلَّم لأصحابها؛ لا تُعرض بعد إنشائها.

## أقسام المدير

الشريط الجانبي مجمّع:
- **الرئيسية** و**الأعضاء** (الحسابات بأنواعها، و«غير مصنف» لموظفي المرتبات، و«مكرر للمراجعة»).
- **التعليم:** الطلاب · الموظفون (صفحة موحّدة لكل العاملين مع «الملف»: البيانات والحلقات والمرتب والغياب والحساب) · الأماكن والحلقات (شريط «يحتاج إجراء»، والعرض حسب المكان أو المشرف أو كل الحلقات، والتعديل الجماعي للمشرف والوقت، و«أدوات»).
- **المالية:** الاشتراكات (التحصيل + تحصيل المعلمين، والتذكير بالسداد) · المرتبات (الكشوف + غياب المعلمين).
- **التواصل:** الإعلانات والملاحظات، ورسائل الطلاب في بطاقة مختصرة.
- **النظام:** الإعدادات (الإعدادات، الصلاحيات، النسخ الاحتياطية، البيانات المعلّقة) · **المعاينة** (رؤية التطبيق كما يراه أي حساب، على الجوال أو التابلت أو الحاسوب، للاطلاع فقط).

الاسم واحد في كل مكان: تعديل اسم الشخص في الأعضاء أو الموظفون أو المرتبات يسري على الآخر. والحلقة تُسمّى باسم معلمها دائمًا.

## الملفات

الملفات تُحمَّل بالترتيب المكتوب في `index.html`؛ كل ملف إضافي يغلّف ما قبله، و`app-actions.js` آخرها.

| الملف | الدور |
|---|---|
| `cloud.js` | المزامنة مع Supabase والنسخة المحلية |
| `app.js` · `app-forms.js` · `app-actions.js` | النواة: البيانات والصفحات والنماذج والإجراءات |
| `payroll.js` · `fees.js` · `collect.js` · `accountant.js` | المرتبات · الاشتراكات · قوائم التحصيل · واجهة المحاسب |
| `perms.js` · `session.js` · `backup.js` · `notes.js` | الصلاحيات · مدة بقاء الدخول · النسخ الاحتياطية · الملاحظات |
| `tables.js` · `selects.js` | الجداول (التكبير والتصدير والطباعة) · القوائم القابلة للبحث |
| `dups.js` · `links.js` · `distribute.js` · `split.js` · `cleanup.js` · `unassigned.js` · `cascade.js` | أدوات تنظيف البيانات وتوزيعها |
| `roles.js` | أنواع الحسابات (الإداري والمشرف العام) والتصنيف والنطاق |
| `staff.js` | صفحة «الموظفون» والاسم الواحد |
| `places.js` | صفحة «الأماكن والحلقات» |
| `preview.js` | «المعاينة» |
| `nav.js` | تجميع الأقسام، وزر الرجوع، والنوافذ المنبثقة، وكبسولة «حلقة»، والتكبير في كل الجداول، وتحسينات السرعة |
| `notify.js` | التذكير بسداد الاشتراك، ورسائل الطلاب في إعلانات المدير |

## إعداد الخادم (Supabase)

نفّذ ملفات `supabase/` في **SQL Editor** بهذا الترتيب لأول تثبيت (كلها آمنة للتكرار):

1. `schema.sql` ثم `admin_bootstrap.sql` (أول حساب مدير)
2. `sync_incremental.sql` ← `sync_scope.sql`
3. `fees.sql` ← `fees_private.sql` ← `perms.sql` ← `accountant.sql` ← `student_edit.sql` ← `collections.sql` ← `notes.sql`
4. `roles.sql` (الإداري والمشرف العام) ← `notify.sql` (تأكيد الدفع والتذكير بالسداد للطلاب) ← `fees_systems.sql` (نظاما الحضور 6 و3 أيام في الاشتراك العام)
5. `backup.sql` ثم `select public.backup_new_token();` ← `backup_status.sql` ← `restore.sql`

ودالة الخادم `supabase/functions/admin-users` (إنشاء حسابات الدخول) تُنشر من لوحة Supabase.

## التشغيل والنشر

- محليًا: `python3 -m http.server 8000` ثم افتح `http://localhost:8000`. وللعمل بلا خادم: أضف `?local=1` إلى الرابط (البيانات في المتصفح وحده).
- النشر: كل دفع إلى `main` ينشره Vercel تلقائيًا (Framework Preset = Other، بلا Build Command).
- بعد التحديث: **Ctrl+Shift+R** على الحاسوب، أو إغلاق التطبيق وفتحه على الجوال.
